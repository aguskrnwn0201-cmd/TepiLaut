# Developer Skill Requirements (Skill.md)

Dokumen ini mendefinisikan keterampilan teknis (*skill set*) yang dibutuhkan bagi developer atau AI agent untuk membangun, memelihara, dan mengembangkan aplikasi ini.

---

## 1. Core Technical Skills

### Frontend Web Development
* **HTML5 & Modern CSS:** Paham konsep *semantic tags*, CSS Flexbox, Grid, dan *mobile-first responsive design*.
* **Tailwind CSS:** Mahir menggunakan *utility classes* Tailwind untuk pembuatan antarmuka cepat tanpa CSS kustom yang berat.
* **Vanilla JavaScript (ES6+) / Framework:** Kuat dalam konsep Async/Await, ES Modules, Event Handling, dan DOM Manipulation.

### PWA & Offline Technologies
* **Web App Manifest:** Konfigurasi `manifest.json` (icons, theme_color, start_url, display mode).
* **Service Worker:** Pemahaman tentang siklus hidup Service Worker (Install, Activate, Fetch) serta strategi *stale-while-revalidate* atau *cache-first*.
* **IndexedDB & Dexie.js:** Penguasaan kueri basis data lokal browser, transaksi data, dan pemetaan relasi data sederhana.

---

## 2. Tools & Build Stack
* **Vite / Parcel / No-Build (CDN):** Kemampuan mengatur proyek ringan tanpa konfigurasi *bundler* berlebihan.
* **Git & GitHub:** Version control standar untuk repositori proyek.
* **Bubblewrap / Capacitor:** (*Opsional untuk fase rilis Android*) Pengetahuan dasar membungkus PWA menjadi APK.
